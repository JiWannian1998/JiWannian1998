# Paper Radar / 论文雷达

A free, evidence-linked academic paper discovery website requested by the repository owner.

This directory is isolated from other projects. It contains no credentials or private research files.

Implementation principles:
- Public bibliographic metadata and openly accessible evidence pages only.
- Never bypass subscriptions, CAPTCHA, login requirements or access restrictions.
- Keep publication dates, attention-event dates and cumulative metrics distinct.
- A source connection failure must not be reported as zero papers.
- Deployment and real-content verification must be checked separately.

Deployment is not yet complete. See the verification workflow for actual network results.
